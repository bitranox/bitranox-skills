# skill-writer checklist - meta-context-watcher (2026-10-19, closed items can hide open ones)

Change: before retiring, migrating or summarising a backlog, scan the full body of every closed
item (Completed/Done/Closed headings and `- [x]` lines) for open markers, adjudicate each hit, and
carry real ones over with their first-raised date before the source file goes.

- [x] Skill type: technique - tested by quote-back (verbatim quote, or NONE).
- [x] RED (text as it stood, opus): NONE for scanning closed items before deleting a TODO.md.
- [x] GREEN (new text, opus and haiku): answered by a direct quote.
- [x] REFACTOR, from the opus GREEN gap: the marker list is now marked case-insensitive. Haiku
      re-test quoted the fix.
- [x] Skill gaps, declined: a TODO.md header with its own closing rule is covered by the existing
      "the header governs that file" rule.
- [x] Lost-result diff: nothing in RED to lose.
- [x] Description unchanged; no table touched.
- [x] Security: no private names; the measured figure is a count only.
